Lockwright is a peer-to-peer password manager. Vaults stay on the device. Sync is device to device. No cloud account.

Community fork of PearPass (Apache 2.0). Not affiliated with or endorsed by Tether Data or the Pears project.

Key features

Device-only storage
Passwords, notes, cards, and identities stay on devices you control. Lockwright does not upload the vault.

Peer-to-peer sync
Pair devices directly. There is no central sync server.

End-to-end encryption
Vault data is encrypted with libsodium primitives. Other devices read it only after you pair them.

Open source
Lockwright is Apache 2.0. The Secfault Security audit applies to PearPass as it existed at the fork point. It does not cover Lockwright changes after that date.

Offline-first
The vault works without a network.

Password generator
Create strong passwords on the device.

Why local storage
Cloud password managers are high-value targets. Lockwright has no cloud vault to breach.

Lockwright is free. The vault is yours.
